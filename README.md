# Discord AI Assistant

AI-powered Discord bot built using Python, discord.py, and Groq API.

## Features

- AI Chat Integration
- Fast Response Generation
- Slash Commands
- Easy Configuration
- Modular Structure

## Tech Stack

- Python
- discord.py
- Groq API

## Installation

Clone repository:

```bash
git clone https://github.com/arcta1/discord-ai-assistant.git
cd discord-ai-assistant
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run bot:

```bash
python bot.py
```
